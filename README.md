# doGood

**doGood** is a personal charity platform designed to support orphaned children and elderly people through donations from friends and the community. The platform aims to simplify and encourage **in-kind donations** such as clothes, food, books, and other essential goods instead of monetary donations.

The project is currently **under active development**, with new features and improvements being added over time.

## Tech Stack

| Category               | Technology                             |
| ---------------------- | -------------------------------------- |
| **Backend**            | Java, Spring Boot                      |
| **Frontend**           | React                                  |
| **Database**           | MySQL                                  |
| **Cloud & Deployment** | Google Cloud Platform (GCP), Cloud Run |

## Project Goal

The goal of **doGood** is to make charitable giving more accessible by connecting people who want to donate useful goods with orphaned children and elderly people who need them.
